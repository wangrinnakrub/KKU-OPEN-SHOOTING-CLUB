# KKU Open Shooting Club

A collaborative web application developed for KKU Open Shooting Club. The project was completed as a prototype but was not adopted for actual club operations.

## Demo

The public pages include clearly labeled sample announcements and competition results. They do not represent real club announcements or scores. The original Supabase project is no longer serving this application, so authentication, registrations, and backend data are unavailable.
